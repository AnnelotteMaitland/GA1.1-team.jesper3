Subteam: subtract(a,b)

1) Brief Description
The subtract(a, b) takes two input variables (a and b) and shows the mathematical difference between these two numbers, such as c = a - b

2) Python example
subtract(5, 6) # Printed message:"When you subtract 6 from 5 you get: -1"

3) Possible problems:
- if we put a different variable, let's say a letter 'A' or a special symbol '&'
- also, there should be only two variables in the brackets as in the case we put more or less fubction will not be able
to read the input data -> the error will arise -> code breaks
